A Superpowered HTML Reset

✨

Class-light & Semantic

Menulis markup HTML5 semantik tanpa dibebani ratusan utility classes. Browser akan merender komponen indah secara otomatis.

🎨

Great Styles with Just CSS

Tidak ada library Javascript yang membengkak. Seluruh styling utama ditenagai oleh CSS murni yang modern dan super cepat.

📱

Responsive Everything

Mendukung layout yang sepenuhnya responsif di semua resolusi, mulai dari ponsel pintar hingga layar lebar desktop ultra-wide.

🌗

Light or Dark Mode

Dukungan mode terang dan gelap bawaan secara otomatis mengikuti preferensi OS pengguna atau dapat dikontrol melalui JavaScript API.

🛠️

Easy Customization

Sesuaikan dengan mudah menggunakan lebih dari 120 variabel CSS kustom untuk mengubah warna, spacing, radius, dan bayangan.

⚡

Optimized Performance

Kecepatan muat maksimal, ramah terhadap SEO, dan siap digunakan bersama HTMX untuk interaksi dinamis tanpa reload halaman.

Embrace the Power of Less

🟢 RDP-UI (Clean Semantic)

HTML yang bersih, mudah dirawat, dan ramah pembaca layar (screen readers). 

<form>
  <label for="email">Email</label>
  <input type="email" id="email" required>
  <button type="submit">Kirim</button>
</form>

🔴 Utility-First CSS

Ratusan class utility yang membingungkan dan sulit dikelola di masa mendatang. 

<form class="flex flex-col gap-4 p-6 bg-white rounded-lg shadow">
  <label class="block text-sm font-bold text-gray-700">Email</label>
  <input type="email" class="w-full px-3 py-2 border rounded shadow-sm focus:outline-none" required>
  <button class="w-full bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded">Kirim</button>
</form>
