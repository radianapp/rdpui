Quick Start

Pelajari cara mengintegrasikan RDP-UI ke dalam proyek web Anda dengan cepat. RDP-UI adalah Design System minimalis berkelas yang dioptimalkan untuk HTMX dan PicoCSS.

1. Instalasi Manual

Unduh berkas CSS dan JS dari repositori dan masukkan langsung ke folder proyek Anda:

<link rel="stylesheet" href="/css/rdp.css">
<script type="module" src="/js/rdp.js" defer></script>

Usage from CDN

Metode tercepat menggunakan RDP-UI adalah melalui CDN resmi Radian Data Platform:

<!-- RDP-UI Stylesheet -->
<link rel="stylesheet" href="https://cdn.radian.web.id/assets/rdp.css">

<!-- RDP-UI Javascript Interactions -->
<script type="module" src="https://cdn.radian.web.id/assets/rdp.js" defer></script>

Install with NPM

Untuk proyek modern berbasis bundler (Vite, Webpack) atau backend Django/Node:

npm install @radiandp/rdp-ui

Atau menggunakan Yarn / PNPM / UV:

yarn add @radiandp/rdp-ui
# atau
pnpm add @radiandp/rdp-ui

Starter Template

Salin template HTML5 boilerplate ini untuk memulai halaman web yang sepenuhnya kompatibel dengan RDP-UI dan PicoCSS:

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>RDP-UI Starter Template</title>
  <!-- PicoCSS -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@picocss/pico@2.1.1/css/pico.min.css">
  <!-- RDP-UI -->
  <link rel="stylesheet" href="https://cdn.radian.web.id/assets/rdp.css">
  <script type="module" src="https://cdn.radian.web.id/assets/rdp.js" defer></script>
</head>
<body>
  <main class="rdp-container" style="padding-top: var(--rdp-space-xl);">
    <h1 class="rdp-display">Halo, RDP-UI!</h1>
    <p class="rdp-body-lg">Mulailah membangun antarmuka web premium Anda.</p>
    <button class="rdp-btn rdp-btn--primary">Tombol Aksi</button>
  </main>
</body>
</html>
